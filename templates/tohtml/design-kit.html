Don'ts

Wrong box-shadow: rgba(0,0,0,0.15) Hardcoded shadow opacity does not adapt to theme or scale.
Right box-shadow: var(--shadow-sm) Token adapts across themes and keeps the scale consistent.
Wrong font-size: 12px Raw px breaks the type scale and makes global changes impossible.
Right font-size: var(--text-sm) Token stays in step with the defined scale.
Wrong z-index: 150 Magic numbers create invisible conflicts across layers.
Right z-index: var(--z-drawer) Named layers are self-documenting and collision-safe.
Wrong color: #31bc81 Hex literals do not flip between light and dark brand values.
Right color: var(--brand-green) Token resolves to the correct hue per theme.
